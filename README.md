# Cisco Packet Tracer Practical Guide  

This repository provides step-by-step instructions for performing several networking practicals using Cisco Packet Tracer. These practicals cover various network configurations and topologies, helping users understand fundamental networking concepts.

---

## Prerequisites  
Before you begin, make sure you have the following:  
- **Cisco Packet Tracer** installed on your computer.  
- Basic understanding of networking concepts.  

---

## Practicals Overview  
This guide covers the following practicals:  

1. **PC to PC Communication**  
   - Study and configure communication between two PCs.  
   - Verify connectivity using the Ping command.  

2. **Network Using Bluetooth (Piconet/Scatternet)**  
   - Create a network using Bluetooth technology.  
   - Understand the difference between Piconet and Scatternet.  

3. **Star Topology Using Hub and Switch**  
   - Design and implement Star topology.  
   - Compare the use of Hub and Switch in Star topology.  

4. **Bus, Ring, Tree, Hybrid, and Mesh Topologies**  
   - Create various network topologies.  
   - Understand the advantages and disadvantages of each topology.  

5. **Initial Switch Configuration**  
   - Configure basic settings on a switch, including:  
     - Hostname  
     - IP address  
     - VLAN configuration  

6. **Initial Router Configuration**  
   - Perform initial setup on a router, including:  
     - Hostname  
     - Interface IP addresses  
     - Routing protocols configuration  

7. **Client-Server Network Implementation**  
   - Establish a Client-Server network architecture.  
   - Configure servers for DHCP, DNS, and Web services.  

8. **Connecting Devices Using a Router**  
   - Implement connectivity between multiple devices using a router.  
   - Set up static and dynamic routing.  

9. **Remote Desktop Sharing within LAN**  
   - Configure remote desktop sharing between PCs within a LAN.  
   - Verify connectivity and remote control functionality.  

---

## Getting Started  
1. **Launch Cisco Packet Tracer** and create a new project.  
2. Follow the step-by-step instructions provided in each practical folder.  
3. Save and document your configurations for future reference.
